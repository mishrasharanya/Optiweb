How This Builder Works

This wizard creates AMPL files for trajectory optimization problems. Fill the steps, review the generated files, then submit them to NEOS.

.dat

Numerical data: grid, seed trajectory, robot table, constraints, RK method, PIM, and optional extra data.

.mod

AMPL model: variables, dynamics, constraints, objective, and optional custom model snippets.

.run

Solver choice, problem block, solve command, output dump, and optional extra run commands.

Wizard Flow

1. Grid
Set the time grid, subphases, gravity, and optional PIM indices.
2. Bézier
Add curve labels, control points, and subgrid mappings.
3. Robot
Upload URDF/AMPL robot data or enter the robot table manually.
4. Constraints
Define physical, virtual, or force constraint rows.
5. RK
Choose a Runge-Kutta preset or enter a custom tableau.
6. q/v/t/u
Provide the seed trajectory for states, controls, and time.
7. Custom
Append extra .dat, .mod, or .run snippets when needed.
8. Solver
Pick one of the supported NEOS AMPL solvers.
9. Review
Inspect generated files, submit to NEOS, and download results.

The generated files use standard AMPL syntax, but the structure follows this app's trajectory-optimization schema. URDF import fills the AMPL robot table for supported joint and inertial fields; you can edit those rows before submitting.
